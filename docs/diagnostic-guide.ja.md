# 初回の診断 · 権限を有効にしない手順

1. 開発 APK を自分で導入し、AU05 のドングルを接続します。
2. 「AU05 の回転入力元を選ぶ」で該当する入力元を選びます。不明なら記録を始めず、そのまま終了してください。
3. 「スクロールを比較」で上下に回し、「補間なし／補間あり」を切り替えて感触を比較します。どちらもこのアプリ内だけの動作です。
4. 必要なら「回転だけを診断・保存」→「回転の記録を開始／停止」で開始し、ゆっくり／速く上下に回します。再度押して停止し、JSONL を保存します。

Accessibility・制限付き設定・IME・firmware は変更しません。「詳細設定」の他アプリ実験は初回には不要です。

導入に追加のセキュリティ設定が必要と表示された場合は、その場で変更せず内容を確認してください。

診断ファイルに入るのは縦回転量・開始からの相対時間・開発版番号・件数だけです。入力文字、ボタンコード、端末識別子、座標、アプリ内容、他のキーボード入力は保存しません。アプリを離れるか選択端末が切断されると記録は停止します。

「合成テスト」は表示処理だけのテストです。AU05 の各ボタン・Galaxy・他アプリの動作を確認した証拠ではありません。ボタンが反応しなくても、その場で不明な権限を有効にせず、まず回転の状態を報告してください。
